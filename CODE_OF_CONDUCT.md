# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers of **Muse for Windows (1MS Studio)** pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment include:
- Demonstrating empathy, kindness, and technical rigor.
- Respecting security boundaries, user privacy, and open-source licensing.
- Giving and gracefully accepting constructive code review feedback.

Unacceptable behavior includes harassment, publishing others' private information or credentials, trolling, insulting/derogatory comments, or submitting malicious code.

## Enforcement

Maintainers at **1MS Studio** are responsible for clarifying and enforcing standards of acceptable behavior via GitHub repository moderation tools (`https://github.com/leminhhuy113/muse-for-windows`).
