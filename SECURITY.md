# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `1.0.x` | Yes |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues privately using **GitHub Private Vulnerability Reporting** on this repository:
- Navigate to `https://github.com/leminhhuy113/muse-for-windows/security/advisories/new` and submit a private advisory.

Include:
1. Affected version, Windows build, and architecture (`x64` / `arm64`).
2. Minimal reproduction steps or proof-of-concept.
3. Expected trust boundary vs. observed behavior.

**Never include real passwords, personal API keys, session cookies, or private account data in vulnerability reports.**

For full architectural security details, see [`docs/SECURITY.md`](./docs/SECURITY.md).
