# Support — Muse for Windows

**Muse for Windows** is an independent open-source project developed by **1MS Studio**.

## Getting Help

1. **Documentation & Troubleshooting:**
   - Vietnamese User Guide: [`docs/USER-GUIDE-VI.md`](./docs/USER-GUIDE-VI.md)
   - English User Guide: [`docs/USER-GUIDE-EN.md`](./docs/USER-GUIDE-EN.md)
   - Troubleshooting Guide: [`docs/TROUBLESHOOTING.md`](./docs/TROUBLESHOOTING.md)
2. **Bug Reports & Feature Requests:**
   - Open an issue on GitHub: `https://github.com/leminhhuy113/muse-for-windows/issues`
3. **Security Vulnerabilities:**
   - Do **not** open public issues for security vulnerabilities. Follow [`SECURITY.md`](./SECURITY.md) to submit a private GitHub Security Advisory.

> **Important:** Do not attach passwords, API keys, authentication cookies, or private conversations to support issues. Use the sanitized report from **Diagnostics -> Copy Sanitized Report**.
