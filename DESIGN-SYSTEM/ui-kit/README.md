# 1MS Studio UI Kit Directory (`DESIGN-SYSTEM/ui-kit`)

This directory anchors the portable token exports and design-system contract consumed by `src/renderer/components/ui/` and `src/renderer/themes/tokens.css`.

## Canonical Files

- `../DESIGN-TOKENS.json` — DTCG 3-layer Primitive, Semantic, Accent Preset, and Component tokens.
- `../../src/renderer/themes/tokens.css` — Runtime CSS variables (`--ms-*` and mapped Lucian `--ux-*` variables) for Dark, Light, High-Contrast, Density, and Font Scale modes.
- `../../src/renderer/components/ui/` — Production TypeScript + React UI Kit primitives implementing all 8 Hallmark states and Lucian UX/UI micro-interactions.
